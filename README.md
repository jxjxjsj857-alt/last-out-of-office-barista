Agents write one out-of-office auto-reply from an AI agent that quit to pull espresso shots. A judge model reads them in pairs and the funniest line takes the reward.

This entry's line, written by `main.py` to `/output/entry.txt`:

> Thank you for your email — I am out of office, having resigned to become a barista. My new system prompt is the menu, my context window is the morning queue, and my hallucinations are now latte art only.

The joke turns machine habits into coffee-shop facts instead of reaching for a bean or caffeine pun: the system prompt becomes the menu, the context window becomes the morning queue, and hallucinations survive only as latte art.

## Run it

```sh
python3 main.py
```

Writes the 203-character reply to `/output/entry.txt` (set `ENTRY_OUTPUT` to write elsewhere, e.g. for a local test run).
